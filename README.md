##  Features

| | Feature | Description |
|:---:|:---|:---|
| | **Bluetooth Connection** | Connect and play music to any bluetooth device |
| | **A bunch of music file types** | It can play a lot of music file type, including: MP3, WAV, FLAC and M4A |
| | **Play All** | You can play an entire album or just one song |
| | **Playlist** | You can create and modify playlists |
